# 🤝 Contribuer à InvoiceFlow

Merci de ton intérêt pour **InvoiceFlow** !  
Voici les étapes pour contribuer au projet.

## 🚀 Démarrage rapide

1. Forke le dépôt
2. Clone ton fork :
   ```bash
   git clone https://github.com/tonpseudo/InvoiceFlow.git
   ```
3. **Crée une branche** pour ta feature ou ton correctif :  
   ```bash
   git checkout -b feature/ma-super-feature
   ```
4. **Commit** tes modifications avec un message clair :
   ```bash
   git commit -m "✨ Ajout de la fonctionnalité X"
   ```
5. **Push** la branche :
   ```bash
   git push origin feature/ma-super-feature
   ```
6. **Ouvre une Pull Request** sur la branche `dev` du dépôt principal.
➡️ Merci d’expliquer clairement ce que ta PR apporte et/ou corrige.

---

## Bonnes pratiques

- Code propre, clair et commenté.
- Utilise TypeScript si possible.
- Respecte la structure du projet existante.
- Évite les dépendances inutiles.
- Les commits doivent suivre une syntaxe simple :
  - ✨ feature: ajout de ...
  - 🐛 fix: correction de ...
  - 🧹 refactor: nettoyage / simplification
  - 📚 docs: mise à jour de la documentation
